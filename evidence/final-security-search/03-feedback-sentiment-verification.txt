IMPLEMENTATION (from the code)
  Provider / model : npm package "sentiment" 5.0.2 (AFINN-165 word list), executed IN-PROCESS
                     in services/search-analytics-service/services/sentimentService.js.
                     No external API, no token, no cost. (A former Hugging Face provider survives
                     only as sentimentService.js.huggingface-backup; HF_TOKEN in the runtime
                     secret is unused.)
  Label            : comparative score > 0 POSITIVE, < 0 NEGATIVE, = 0 NEUTRAL
  Confidence       : heuristic |s| / (1 + |s|), 4 decimals (documented as not calibrated)
  Submission       : POST /api/articles/:id/feedback {comment, turnstileToken}
                     requireLogin -> rate limit "feedback" (20 per window, per IP) ->
                     requireBrowserWrite (Origin + CSRF) -> Turnstile -> feedbackService.comment()
  Trigger/storage  : INSERT article_feedback (sentiment_status 'pending') FIRST, then classify,
                     then UPDATE status/label/confidence (update errors are logged, row kept).
  Retrieval        : GET /api/analytics/overview (requireReviewer) -> sentimentBreakdown =
                     completed rows grouped by label; frontend/js/analytics.js renders this array
                     verbatim in the "Feedback Sentiment" dashboard section.
  Env / credentials: none for sentiment; TURNSTILE_SECRET_KEY (runtime secret) for submission.
  Duplicate rule   : required for helpfulness VOTES (SECURITY.md T5: one per user per article,
                     UNIQUE + upsert). Written feedback has no uniqueness requirement.
