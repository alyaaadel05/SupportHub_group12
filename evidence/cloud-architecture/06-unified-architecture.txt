5. MUST FLOCI RUN DURING THE DEMONSTRATION?  YES.
   Needs Floci (and the ECS workers):  submission -> SQS -> editorial review queue; SNS
     publication event -> Lambda receipt; S3 version backups and CSV exports; DynamoDB live
     counters; CloudWatch metrics; Identity SNS security alerts; Secrets Manager for the workers.
   Works without Floci (Vercel + Neon only): login/registration, article CRUD, approve/publish of
     already-queued reviews, search, feedback/sentiment, analytics overview. Events written while
     Floci is down stay in the PostgreSQL outboxes and are delivered after it starts (durable).
   Hosting limitation (free budget): the Floci host is a team laptop that must be switched on and
     online for the demo; Workers VPC is free only while in beta (post-beta pricing not stated);
     Floci on Windows took ~4.5 min to restart.
